# Prakhar Jain — Portfolio

CHECK ON:- prakhar-jain-portfolio.vercel.app

A responsive personal portfolio website built from scratch with **HTML, CSS and JavaScript**.

> A developer-focused portfolio showcasing projects, skills, learning journey and contact information.

## ✨ Highlights

- Responsive desktop and mobile layout
- Animated hero section
- Custom cursor glow effect
- Scroll progress indicator
- Scroll reveal animations
- Interactive project-card tilt effect
- Mobile navigation menu
- Project showcase for **NEXALITH** and **FixMyCity AI**
- Clean dark UI with a distinctive neon-lime visual identity
- No framework or build step required

## 🚀 Run Locally

No installation is required.

### Option 1 — Open directly

Open `index.html` in your browser.

### Option 2 — VS Code Live Server

Open the folder in VS Code and run it with the **Live Server** extension.

## 🌐 Deploy

This is a static website, so it can be deployed easily using:

- GitHub Pages
- Vercel
- Netlify

### GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select the main branch and `/root` folder.
4. Save and wait for GitHub Pages to publish the site.
